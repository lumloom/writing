# 하루문장

매일 하나의 기억 글감을 받아 부담 없이 글을 쓰고, 날짜별 기록과 루틴을 관리하는 글쓰기 앱입니다.

## v0.3 기능

- 오늘의 기억 글감 표시
- 다른 기억 글감으로 바꾸기
- 앱이 준 글감 없이 시작하는 자유 글쓰기
- 글감 씨앗 보관
- 10개 카테고리, 총 200개 키워드 기반 글감 제공
- 키워드와 질문 템플릿을 조합해 오늘의 기억 질문 자동 생성
- 글감별 첫 문장 예시 자동 생성
- 제목과 본문 작성
- API 비용 없이 작동하는 기억 도우미
  - 제목 씨앗 추천
  - 기억 이어가기 질문 제안
  - 한 가지 더 떠올려보기
  - 오늘의 문장 뽑기
- 본문 길이에 따른 따뜻한 글쓰기 코치 메시지
- 브라우저 저장소에 기록 저장
- 하루에 여러 편 작성 가능
- 날짜별 기록 목록과 저장된 글 다시 읽기
- 저장된 글 수정
- 저장된 글 삭제
- 저장된 글의 기억 태그, 기억 키워드, 오늘의 문장 자동 정리
- 실제 작성한 글에서 나온 단어를 누적해 기억 도감 표시
- 캘린더 날짜 클릭으로 해당 날짜 기록만 보기
- 이번 달 작성 캘린더와 날짜별 작성 편수 표시
- 연속 작성일, 총 기록, 오늘 작성 수, 총 글자 수, 자주 꺼낸 기억 표시
- 작성 중인 글이나 저장된 글에서 마음에 드는 문장 선택 후 문장 씨앗으로 저장
- 보관한 글감 씨앗과 문장 씨앗 삭제
- Obsidian에 넣기 좋은 Markdown 파일로 전체 기록 저장
- 추후 실제 AI API를 붙일 수 있도록 데이터와 규칙 기반 엔진 분리

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

로컬 서버로 확인하려면 앱 폴더에서 아래 명령을 실행합니다.

```bash
python -m http.server 4173
```

그 다음 브라우저에서 `http://127.0.0.1:4173/` 주소를 엽니다.
