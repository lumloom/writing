# 하루문장 Writing2

Lumloom의 브랜드 감성에 맞춰 새롭게 구성한 글쓰기 앱입니다. 조용한 서재에서 종이를 펼친 듯한 경험을 목표로 색감, 타이포그래피, 여백, 모바일 글쓰기 흐름을 다시 설계했습니다.

## 유지한 기능

- 기존 글감 데이터와 질문 생성 엔진
- 글 작성, 저장, 수정, 삭제
- 날짜별 기록과 검색, 글별 Markdown ZIP 내보내기
- 글감·문장 보관함
- 연속 기록과 통계
- 기억 도우미와 기억 도감
- 기존 `haru-writing-app` 로컬 저장 데이터 구조

## 이번 확장

- 글쓰기 도움 카드와 자동 첫 문장 기능 제거
- 12개 대분류, 60개 중분류, 600개 소재로 글감 확장
- 회상뿐 아니라 관찰, 취향, 사회, 상상, 가치 질문까지 질문 범위 확대
- 대분류 선택 후 해당 범위에서 무작위 글감 변경
- 차분한 `서재 모드`와 선명한 `상큼 모드` 즉시 전환
- 선택한 대분류와 화면 콘셉트를 기존 저장 데이터에 안전하게 추가 저장
- 기록마다 `YYYY-MM-DD_제목.md` 파일을 만들고 전체 기록을 ZIP으로 한 번에 저장

## 실행

별도 빌드 과정이 없는 정적 웹앱입니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 배포 참고

기존 사이트와 같은 도메인에서 제공하면 동일한 `localStorage` 키를 사용해 기존 기록을 그대로 읽습니다. 다른 도메인이나 로컬 파일로 열 경우 브라우저 보안 정책상 저장소가 별도로 분리될 수 있습니다.

## Lumloom 계정 동기화

- 기존 `haru-writing-app` 로컬 저장을 그대로 유지하면서 Supabase Auth 동기화를 선택적으로 사용할 수 있습니다.
- 처음 로그인한 뒤 `기존 기록 올리기`를 눌러야 이 기기에 있던 기록이 클라우드에 등록됩니다.
- 같은 기록이 이 기기와 클라우드에서 모두 달라졌다면 어느 쪽을 사용할지 직접 선택합니다.
- Supabase 프로젝트에는 `supabase/lumloom-sync.sql`을 한 번 실행하고, Auth 리디렉션 URL에 배포 주소를 등록해야 합니다.
- Markdown ZIP과 Obsidian 저장 기능은 계정 동기화와 별도로 계속 사용할 수 있습니다.
